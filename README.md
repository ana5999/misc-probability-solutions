# Probability Solver

A Python project demonstrating core probability and statistics concepts through analytical calculations and simulation.

## Features

- Probability of rolling a die greater than a target value
- Probability of two dice summing to a target value
- Probability of at least one head in two coin flips
- Expected value of a fair die
- Expected lottery winnings
- Uniform distribution probability estimation
- Conditional probability examples
- Bayes' Theorem examples

## Topics

- Probability
- Expected Value
- Conditional Probability
- Bayes' Theorem
- Monte Carlo Simulation

## Requirements

Python 3.10+

## Run

```bash
python probability_solver.py
```
